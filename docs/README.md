# Documentation

This directory contains the canonical Project Flow documentation.

- `spec.md` — product/runtime specification.
- `architecture.md` — lifecycle ownership, module boundaries, and implementation shape.
- `integrations.md` — boundaries for `pi-web-access`, `pi-subagents`, and future capability providers.
- `validation.md` — local validation strategy and evidence requirements.
- `protocols/codebase-reading.md` — shallow-first code and memory reading protocol.
- `reference/references.md` — design references and inspiration.
- `adr/` — accepted architecture decision records.

Historical planning notes have been migrated into these canonical docs and removed.
